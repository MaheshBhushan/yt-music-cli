HELP & ACCOUNT CONTROLS

Keep the music moving.

Help for installation, Google sign-in, and taking control of your data.

Contact the developer

Mahesh Koduri · mkoduri73@gmail.com

For reproducible bugs, open a GitHub issue. Include your operating system, ytm --version, what you ran, and the error message. Redact email addresses and private content. Never post tokens, cookies, passwords, or credential files.

Google says the app is only available to testers

This is controlled by the Google Cloud project’s publishing and verification settings, not by reinstalling ytm. Contact the developer with the account you want to use via private email. While the app is in Testing, only accounts added as test users can authorize it. Public availability and any Google verification review are separate from publishing a software release.

The sign-in browser did not open

Run ytm auth and open the printed authorization link on the same computer. The Desktop flow waits for a local browser callback. After consent succeeds, return to the terminal. Never send the authorization URL or returned code to another person.

Updating on Windows

Close ytm before running the external update command. For a normal pip installation:

py -m pip install --upgrade ytm

If you installed with pipx or uv, use that installer’s upgrade command instead. The ytm update command in current releases prints guidance to avoid replacing a running Windows launcher.

Disconnect or remove local data

Remove ytm from Google Account connections, then follow the local-data removal instructions in the privacy policy. Removing authorization and deleting local files are separate steps.
